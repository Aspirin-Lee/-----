# LabDay 实验日程 0.2
安卓个人实验安排与记录。代码在 GitHub，CI 在 GitHub-hosted runners 编译、执行服务端测试和安卓模拟器测试。仓库只包含虚构测试数据。

## 使用流程
1. 在“Notion 任务与连接”填写自己的 HTTPS 网关地址和 APP_ACCESS_TOKEN（不是 NOTION_TOKEN）。密钥使用 Android Keystore 加密保存。
2. 读取任务，打开原方案文字/图片链接，选择“安排本次实验”生成独立草稿；设置日期。
3. 自动保存草稿，记录项目、样本、设计、结果、异常和图片说明，语音可填多个字段。
4. 保存到手机，或“保存并排队同步到 Notion”。同一方案可复制为多次执行。
5. 在“同步队列”查看结果、失败和需核查任务。原方案不替换，同步结果追加为独立折叠记录。
6. 定期导出 ZIP，包含 JSON、Markdown 和原图；恢复会新增副本并保留现有数据，不自动恢复同步队列、提醒或密钥。

## 功能
- 今天/明天/后天、日期选择、全部历史、全文搜索。
- SQLite 持久化记录、独立草稿、不可变同步快照及失败重试。
- 系统语音、拍照、选图、每图说明、原图查看、缩略图、EXIF方向修正。
- 自定义实验模板和新的独立执行记录。
- 网络约束的后台同步；结果不确定时暂停并要求人工核查，原编号重试提供服务端去重。
- 多个步骤计时提醒（系统可能延迟），设备重启后恢复未来提醒。
- 服务端限制到配置的数据源，认证读写、请求大小/并发限制、错误脱敏。

## 部署与权限
Render 使用 render.yaml（Free 计划）；具体配置见 docs/NOTION_SETUP.md。
Notion 内部连接需“读取内容”和“插入内容”能力，并授权目标页面。不会修改或删除既有块，不需要“更新内容”能力。
上传到 Notion 的图片是最长边不超过1600像素的 JPEG 副本；每次记录最多3张。原图保存在手机和ZIP备份。
单张本机图片上限25MB，上传压缩图上限2MB。超限会明确提示，不静默丢弃。

## 安装与验证
Actions 的 Android APK 工作流产出 LabDay-debug-apk；仍为调试版。
0.1 的临时调试签名可能与0.2不兼容：如已保存真实数据，不要直接卸载旧版；先保留旧版数据并联系维护者。
从0.2起 CI 缓存调试密钥，正式发布仍需独立、稳定的发布签名。
自动测试使用虚构数据，不向真实 Notion 写入。上线前仍需真机验证相机、语音、通知、后台调度及真实授权。
当前不会做双向自动覆盖，不支持自动创建新的 Notion 实验方案、秒级精确提醒、AI转写整理或原始录音归档。
单次完整备份上限300MB，文字清单/Markdown各上限25MB；导出前会检查，避免产生自身无法恢复的备份。备份未加密，请选择可信存放位置。原方案的复杂表格、子页面和嵌入数据库可能仅显示提示，需打开 Notion 查看完整内容。
