# 开发路线与验收
## 0.1 本机原型
- 今天、明天、后天；编辑标题、日期、设计、结果及完成状态。
- 本机持久化；系统语音输入；图片选择及本机保存。
- 不预置真实数据。Notion 未连接；没有云端图片上传。
- 必测：保存后重启、跨日筛选、无语音服务、拒绝选择图片、超限图片。
## 0.2 Notion 接入
- 私有服务端保管 Notion integration token；Android 不内置共享密钥。
- 用户在 Notion 授权指定数据库；配置 data_source_id 和字段映射。
- 数据源字段建议：标题、计划日期、状态、项目、样本编号。设计和结果作为页面内容。
- 先只读导入，再实现 App 管理的独立记录块追加，避免替换用户既有页面。
- 手机数据库升级为 Room，增加持久化 outbox、稳定操作 ID、重试和冲突提示。
- 图片本机成功和 Notion 上传成功分开显示；使用 Notion File Upload API。
- 不将 Notion 工作区 ID、页面标题、实验内容、令牌写入此公开仓库。
## 0.3 日常可用
- 备份与 Markdown/JSON 导出、实验模板、步骤计时器、提醒。
- 语音转写保留人工确认，尤其是浓度、温度、样本编号。
- 真机验证后台提醒、断网重试、时区和午夜切换、大图内存、系统进程回收。
## 云端开发
- GitHub 仓库存代码；GitHub-hosted Actions 进行 lint 和构建 APK。
- Actions 工作流不等于自动编程代理，不执行无限后台开发。
- Codespaces 用于浏览器交互开发，会因空闲停止。
- Codex Cloud 需可运行的已发布环境，确认后才能提交异步开发任务。
- 当前连接发现的环境 runnable=false，尚未启动云端编程代理。
